# demo-assets —— 演示动图里粘的那三件附件

README 演示动图（`docs/demo.gif`）里粘进笔记的三件东西，全部来自这个目录，**没有一件来自用户自己的库**。

| 文件 | 是什么 | 从哪来 | 体积 |
|---|---|---|---|
| `photo.jpg` | 240×160 风景照（雪坡孤树） | Pexels [30473642](https://www.pexels.com/photo/30473642/)，Erik Schereder，Pexels License | 3 KB |
| `chart.png` | 220×140 柱状图 | 用 Pillow 画的（几条矩形 ＋ 轴线） | 0.4 KB |
| `meeting-notes.pdf` | 842×300 **横版**单页（标题 ＋ 三行字） | 手写最小 PDF 结构（Helvetica，无第三方库） | 0.8 KB |

## 为什么是这三件

- **照片**：Pexels License 免费商用、不要求署名、可修改；下载后居中裁 3:2、缩到 240 宽、**重新编码丢掉全部
  EXIF**（相机/GPS 不该跟着动图一起公开）。
- **图表**：第三件要"看起来是另一种东西"，但**不能依赖任何原生控件**（见下）。
- **PDF 是横版**：宿主 1.14 的 PDF 嵌入按**页高**铺开，A4 竖版会把第三件挤出屏幕；
  842×300 的"幻灯片"嵌入后约 190px 高，三件才能挤进一屏。
- 顺序是 **照片 → 图表 → PDF**：PDF 排最后，它铺多高都不影响前两件。

## ⚠️ 为什么第三件不是音频（旧版用的是 `.wav`）

1.8.0 那版用的是 `voice-memo.wav`。这次换掉了，**不是产品坏了，是截不到**：

| 实测 | 结果 |
|---|---|
| `<audio>` 元素 | 在，`readyState=4`、`duration=1`、高 42px、`src` 已是本地 `app://` |
| `Page.captureScreenshot` 截出来 | **一片空白**（原生控件不进 CDP 截图） |

⇒ 观众会以为播放器坏了。换成第二张图最稳：渲染完全由页面自己画，截得到。
