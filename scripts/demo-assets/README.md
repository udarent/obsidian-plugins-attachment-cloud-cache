# demo-assets —— 演示动图里粘的那三件附件

README 演示动图（`docs/demo.gif`）里粘进笔记的三件东西，全部来自这个目录，**没有一件来自用户自己的库**。

## 怎么重拍（两条命令，顺序不能反）

```bash
node scripts/capture-demo.mjs      # ① 录帧 → demo-frames/（PNG 序列 ＋ timeline.json），跑完自动清场
node scripts/capture-demo-gif.mjs  # ② 合成 → docs/demo.gif（ffmpeg ＋ libass 字幕）
```

- 字幕文案写在 `capture-demo.mjs` 的 `mark(...)` 里（主行英文、次行中文）—— 合成脚本只消费它，**别去那边改文案**。
- ⚠️ 录制要**独占 Obsidian**：脚本会临时开一个一次性空库（`%TEMP%/acc-demo-vault`）、改宿主语言、
  自己启一个带调试端口的宿主 ⇒ **跑之前先关掉所有 Obsidian**，否则连不上调试端口。
- ⚠️ `demo-frames/` **不入库**（只入库 `docs/demo.gif`）：中间产物几十张 PNG、几 MB，重拍时重跑即可。
- 合成需要 ffmpeg（本机没有系统级的那份）：`FFMPEG_PATH` → 装过的 `ffmpeg-static` → 托管工作区那份 → `PATH`
  依次找，细节在该脚本头部。

| 文件 | 是什么 | 从哪来 | 体积 |
|---|---|---|---|
| `photo.jpg` | 260×173 风景照（Moraine Lake 日出倒影） | Pexels [417074](https://www.pexels.com/photo/417074/)，James Wheeler，Pexels License | 13 KB |
| `chart.png` | 220×140 柱状图 | 用 Pillow 画的（几条矩形 ＋ 轴线） | 0.4 KB |
| `meeting-notes.pdf` | 842×300 **横版**单页（标题 ＋ 三行字） | 手写最小 PDF 结构（Helvetica，无第三方库） | 0.8 KB |

## 另外两个"躺在库里、没上传也没人引用"的文件

第 5 步要演筛选（胶囊上带件数），空库里只有那三件上传过的，`Not uploaded` / `To clean up`
永远是 0 —— 点下去清单是空的，观众就看不到"筛选真的在筛"。

⚠️ 它们**不单独存资产**：录制脚本拿上面 `chart.png` / `meeting-notes.pdf` 的字节另存成
`notes/whiteboard.png` / `notes/old-handout.pdf`（见 `capture-demo.mjs` 的 `EXTRA_FILES`）。
名字刻意起得像"人自己放进去的旧东西"，不像测试夹具。

## 为什么是这三件

- **照片**：Pexels License 免费商用、不要求署名、可修改；下载后居中裁 3:2、缩到 260 宽、**重新编码丢掉全部
  EXIF**（相机/GPS 不该跟着动图一起公开）。
  ⚠️ 尺寸上限是**三件同屏**卡的：260 宽（173 高）是现在这一屏还能塞下照片 ＋ 图表 ＋ PDF 的极限，
  再大最后一步就会把 PDF 顶出画面（`capture-demo.mjs` 有守卫会直接抛错）。
  ⭐ 出图前加 **0.5px 高斯模糊**：260 宽下肉眼看不出，但森林/水波这类高频细节最吃 GIF 字节
  —— 同一张照片 **242 → 213 KB**（−12%），比降色深（96→64 只省 11 KB）划算得多。
- **图表**：第三件要"看起来是另一种东西"，但**不能依赖任何原生控件**（见下）。
- **PDF 是横版**：宿主 1.14 的 PDF 嵌入按**页高**铺开，A4 竖版会把第三件挤出屏幕；
  842×300 的"幻灯片"嵌入后约 190px 高，三件才能挤进一屏。
- 顺序是 **照片 → 图表 → PDF**：PDF 排最后，它铺多高都不影响前两件。

## ⚠️ 为什么第三件不是音频（旧版用的是 `.wav`）

1.8.0 那版用的是 `voice-memo.wav`。这次换掉了，原因**不是"截不到音频"**（那只猜错了一半）：

| 场景 | 结果 |
|---|---|
| 笔记里直嵌本地文件（`![[voice-memo.wav]]`） | 播放器**正常截图**（三种截法都试过：默认 / `fromSurface:false` / `captureBeyondViewport`） |
| 走**粘贴 → 上传 → 改写链接**（`![](https://cdn.example.com/…wav)`） | 元素在、`readyState=4`、`duration=1`、高 42px、`src` 已是本地 `app://`，**画面一片空白** |

⇒ 差别不在截图能力，而在**这个状态**。看起来是"远端地址被换成副本之后，原生播放器控件不再绘制"，
像产品侧的问题（**未确认、未修**）。演示不能带着一块空白，所以换成第二张图。

想复现：把 `PASTE_FILES` 里换成 `voice-memo.wav`（16bit PCM）再跑一遍 `capture-demo.mjs`。

## 合成参数（2026-10-24 实测）

新版动图要装下"七步 ＋ 一张六列表格"，体积比纯文本画面贵得多。试过的杠杆：

| 参数 | 结果 |
|---|---|
| 宽度 1080（原生窗口宽） | **205 KB** ← 采用 |
| 宽度 960 / 900 | 287 / 278 KB（**反而更大**：非整数缩放让文字边缘出灰边，每帧更难压） |
| 调色板 96 → 64 色 | 只省 ~11 KB，照片开始出色阶 |
| 不抖动（`dither=none`） | 与 bayer5 基本持平，但天空/雪坡出色阶 |

⇒ **别为了体积缩宽**：整数 1:1 缩放最省。真要更小只能减时长或减画面里的信息量。
