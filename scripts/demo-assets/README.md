# demo-assets —— 演示动图里那张照片

`photo.png` 是 README 演示动图（`docs/demo.gif`）里"粘贴的那张照片"。

## 它从哪来

2026-10-24 用户口径：「采用的图片也不太合适，应该用**之前的风景照**」——
指的是 1.2.0 那版演示动图（提交 `d6f6a01`）里贴的那张（琥珀色玻璃球 / 蓝调光的地面）。

⚠️ **原文件已经不在了**：它当年在演示库里，后来库被清理过。所以这张是从旧动图里裁出来的：

| 步骤 | 说明 |
|---|---|
| 取帧 | `git show d6f6a01:docs/demo.gif` → 该版第 109 帧（1080×648） |
| 裁切 | 照片在画面里只有 **211×140** 像素（`(206,162)-(417,302)`） |
| 柔化 | `MedianFilter(5)` ＋ `GaussianBlur(0.5)`：把 GIF 的 256 色抖动压掉，否则放大后是一格一格的 |
| 放大 | 到 **400×265**（`BICUBIC`）＋ 轻锐化 `UnsharpMask(1.1, 45%, 4)` |

⚠️ **别再往上放大**：源只有 211×140，再大只会更糊。真要清晰版，只能拿原始照片重做。

## 为什么放进仓库

录制脚本（`scripts/capture-demo.mjs`）每次都要读它 —— 不入库的话，换台机器就重录不出来。
约 90 KB，比一张截图大不了多少。
